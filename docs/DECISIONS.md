### A12 — 왜 규칙 엔진을 버렸나

한때 `audit/rules.py`에 R1~R8과 한국어 문장이 있었다. 지운 이유:

- **규칙의 가치는 문장이 아니라 "무엇을 계산할지 고른 것"이었다.** 거래 2,456건을 LLM에 던지면 이체의 비대칭을 못 찾지만, `transfers.external.net = 8,917,889`을 보여주면 당연히 알아챈다. 그건 판단이 아니라 **집계**다.
- 우리가 문장을 만들어도 LLM이 다시 쓴다. 이중 작업이다.
- 한국어 조사 처리 함수(`josa()`)를 직접 짜고 있었다는 게 계층을 잘못 그었다는 신호였다.

**남긴 것**: 모든 산수, 파생값, 데이터 품질 신호(`dataQuality.flags`).
**버린 것**: 심각도 판정, 제목·본문·레버 문장, 표기 헬퍼.

> 단, **못 믿을 값은 키 자체를 만들지 않는다** (`savingsRate`). null로 두면 인용되고, 없으면 인용될 수 없다. 우리는 유저의 프롬프트를 소유하지 않으므로 **파일 자체가 유일한 방어 수단**이다.

## 3. 검증된 기술 사실

전부 **실측**이다. 추정 아님.

| 사실 | 값 / 결과 |
|---|---|
| 뱅샐 zip 암호화 | **ZipCrypto** (AES 아님), deflate |
| 비밀번호 | **필수.** 매 내보내기마다 유저가 새로 설정 |
| Apps Script — GCP OAuth 없이 Gmail 읽기 + Drive 쓰기 | ✅ |
| Apps Script — ZipCrypto 자체 구현 | ✅ **550ms**, 121,210 bytes, 로컬과 바이트 일치 |
| Apps Script — xlsx → Sheets 변환 | ✅ 2,457행 × 10열 |
| **Apps Script — 전 구간 1회 실행** | ✅ **14초** (Gmail→해제→변환→집계→Drive 저장) |
| **`getValues()` vs 로컬 파서** | ✅ **숫자 완전 일치.** 수식 셀·Date 객체 우려는 실현되지 않았다 |
| **산출물 크기** | 압축 7,951자 / 정렬 13,334자 → **14,831 bytes** |
| V8 런타임 | **ON**. Rhino는 2026-01-31 sunset |
| `gmail.readonly` | **restricted scope** → Testing 상태 refresh token **7일 만료** |
| ChatGPT 커넥터 | **Plus 이상 유료 전용** |
| Gemini + 개인 Gmail | 미지원 근거 존재 |

### Drive 커넥터 (2026-08-08 재측정)

| 형식 | 읽히나 |
|---|---|
| `application/json` | ✅ |
| `text/plain`, `text/markdown` | ✅ |
| Google Docs | ✅ (줄마다 빈 줄이 끼어 낭비) |
| Google Sheets | ✅ (마크다운 표로 깔끔) |

- **갓 만든 파일은 몇 분간 빈 문자열로 나온다.** 2분 시점 빈 값 → 8분 시점 정상. 크기·MIME과 무관.
- **마크다운 특수문자가 이스케이프된다.**
  - 깨짐: `[ ] < > ! \ # * _ ~ ` `
  - 안전: `{ } ( ) : ; , . ? / | + = % & @ $ " ' -`
  - → JSON 뼈대(`{ } " : ,`)는 멀쩡하고 배열 괄호만 `\[ \]`가 된다. 엄격한 파서는 깨지지만 LLM은 읽는다.
  - → **식별자에 밑줄을 쓰지 않는다** (snake_case → camelCase).

### 수입 미포착의 정체 (B0, 규명 완료)

수입 881만 vs 지출 2,018만 = **−1,136만원**. 원인은 뱅샐 1년 한도가 **아니었다** (데이터는 12개월 균일, 결제수단 11개가 첫 달부터 등장).

```
이체 전체 순액            +9,124,559
├ 본인 명의(성대규)        +206,670   ← 0에 가깝다. 계좌 연동은 정상
└ 그 외 (external.net)  +8,917,889   ← 외부에서 들어온 돈
```

명백한 수입인데 이체로 분류된 것: 퇴직정산 902,102 / 학업장려금 500,000 / 주식회사 팀블 483,500 / 직무발명보상금 156,000. **나머지 개인 송금은 수입인지 차입인지 사용자만 안다.**
