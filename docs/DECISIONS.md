## 2. 아키텍처

| # | 결정 | 근거 |
|---|---|---|
| A1 | **인제스트는 Google Apps Script 전담** | `gmail.readonly`는 restricted scope → 다른 런타임은 Testing 7일 만료 / 프로덕션은 앱심사+CASA. **Apps Script만 이걸 우회한다** |
| A2 | **Drive가 단일 진실 원천** | 좌우로 갈라 두면 노트북과 폰이 다른 걸 본다. 로컬 MCP는 Drive for Desktop 동기화 폴더를 읽는다 |
| A3 | **Drive에는 계산이 끝난 결과를 놓는다** | LLM에 원본을 던지면 함정 3종을 매번 새로 밟는다 (개발 중 실제로 세 번 다 틀렸다) |
| A4 | **모바일·웹 채널 = Drive 커넥터** | 인제스트가 자동이면 대화로 트리거할 이유가 없다 |
| A5 | **MCP 서버 = 데스크톱 채널** | 로컬 stdio는 웹·모바일에서 불가. 대신 OpenClaw·Cursor·Codex·Claude Desktop을 한 번에 커버 |
| A6 | **웹앱·네이티브 모바일앱 제외** | 서버비·LLM 비용을 우리가 못 낸다. 우리 서버에 데이터를 두면 차별점 (2)를 스스로 버린다 |
| A7 | **ZipCrypto 직접 구현** | `Utilities.unzip()`은 암호 zip 불가. UnzipGs는 V8을 꺼야 하는데 Rhino가 sunset됨 |
| A8 | **xlsx는 Drive API로 Sheets 변환** | `openpyxl` 이식이 통째로 불필요해진다 |
| A9 | **Python 참조 구현 유지** | Apps Script의 스펙이자 검증 기준. 실데이터 회귀 테스트 |
| A10 | **토스증권 Open API 불필요** | 뱅샐 `5.투자현황`에 종목별 원금·평가·수익률이 이미 있다. readonly만 필요 |

## 3. 검증된 기술 사실

전부 **실측**이다. 추정 아님.

| 사실 | 값 / 결과 |
|---|---|
| 뱅샐 zip 암호화 | **ZipCrypto** (내보내기 2건, AES 아님), deflate, 117KB |
| 비밀번호 | **필수.** 매 내보내기마다 유저가 새로 설정 |
| Python 표준 `zipfile` | ZipCrypto 해제 **가능** (`pyzipper` 불필요) → **LLM 코드 인터프리터에서 바로 열림** |
| Apps Script — GCP OAuth 없이 Gmail 읽기 + Drive 쓰기 | ✅ 실증 |
| Apps Script — ZipCrypto 자체 구현 | ✅ **550ms**, 121,210 bytes, 로컬 Python과 일치 |
| Apps Script — xlsx → Sheets 변환 | ✅ 2457행 × 10열, 시트 2개 |
| V8 런타임 | **ON**. Rhino는 2026-01-31 sunset |
| `gmail.readonly` | **restricted scope** → Testing 상태 refresh token **7일 만료** |
| Claude Drive 커넥터 + JSON | 읽힘. 단 **미문서화 동작**, 마크다운 이스케이프 오염, 19KB는 빈 문자열 |
| ChatGPT 커넥터 | **Plus 이상 유료 전용** |
| Gemini + 개인 Gmail | 미지원 근거 존재 |

## 4. 뒤집힌 결정 — 되돌아가지 말 것

| 한때 정했던 것 | 지금 | 무효화한 근거 |
|---|---|---|
| "분석하기 전에 **감사**한다"를 전면에 | 감사는 **기본**으로 강등 | 사용자가 원하는 건 목표 달성. 감사는 수단 |
| 타겟 = **준개발자** | **사회 초년생**으로 다시 넓힘 | `.mcpb` 원클릭 + Apps Script로 이탈 지점이 사라짐 |
| Tier 2 **Claude Code 플러그인** 중심 | **Apps Script + Drive 커넥터** | 웹·모바일이 로컬 MCP에 못 닿음. 플러그인은 데스크톱 전용 |
| **토스증권 Open API** 필요 | **불필요** | 뱅샐에 종목별 손익이 이미 있음 |
| **로컬 우선**(launchd) | **Drive 단일 진실 원천** | 로컬은 7일마다 재인증 → 자동화가 아님 |
| **V2 하이브리드**(노트북 켤 때 처리) | **V1 완전 자동**(Apps Script) | ZipCrypto 자체 구현으로 임계 경로가 열림 |
| **UnzipGs**(zlib.js) | **직접 구현** | Rhino sunset(2026-01-31)으로 V8을 끌 수 없음 + 5년 방치 라이브러리 |
| 설치 **5단계 10분** | **3조작** | GCP OAuth는 Apps Script에 불필요했음 (문서 오류) |
| 뱅샐 내보내기 **"탭 3번"** | 홈→메뉴→설정→내보내기→파일로 받기→**비번 입력** | 웹 대화 표현을 검증 없이 계승했음 |
| 주기 **"월 1회"** | **유저가 정함** | 내가 만든 가정. 확정 사항 아니었음 |
| MCP **선택으로 강등** | **부분 승격** | OpenClaw(MIT, 로컬, 아무 LLM, MCP stdio+HTTP)가 "멀티 LLM + 로컬" 요구를 유일하게 만족 |

> **`docs/project-brief.md`와 `docs/architecture.md`는 상당 부분 무효다.** 이력으로만 참조할 것.
