# 돈동생 설치하기

> 자산 같이 봐주는 똑똑한 동생.
>
> 설치 자체는 5분쯤 걸려요. 다만 뱅크샐러드에서 데이터를 보내고 메일이 오는 걸
> 기다려야 해서, 처음 결과를 보기까지는 **20~30분** 잡아 주세요.

---

## 필요한 것

- **구글 계정** (뱅크샐러드 내보내기를 받는 메일 주소)
- **뱅크샐러드 앱**
- **AI 구독 하나** — Claude나 ChatGPT, Gemini에 **매달 돈을 내고 있으면** 됩니다.
  (무료로 쓰고 계시면 구글 드라이브 연결이 안 돼요)

> ⚠️ **뱅크샐러드에 가입한 이메일이 위 구글 계정과 같아야 해요.**
> 뱅샐이 보내는 메일을 돈동생이 읽어야 하거든요. 네이버 메일로 가입하셨다면
> 뱅샐 앱에서 내보낼 때 받는 주소를 지메일로 바꿔 주세요.

---

## 1. 설치 — 3조작

### ① 사본 만들기

**[👉 돈동생 시트 사본 만들기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy)**

링크를 열면 "사본 만들기" 버튼이 나옵니다. 누르면 **내 구글 드라이브에** 복제됩니다.

### ② 처음 설정하기

복제된 시트 상단 메뉴에서 **`💰 돈동생` → `① 처음 설정하기`**

> 메뉴가 안 보이면 시트를 새로고침하세요. 처음 열 때 몇 초 걸립니다.

뱅크샐러드에서 **데이터를 내보낼 때 쓸 비밀번호**를 입력합니다.

> **아직 뱅크샐러드에서 아무것도 안 보내셨어도 괜찮아요.** 앞으로 쓸 값을 미리 정하는 거예요.
>
> ⚠️ 뱅크샐러드는 내보낼 때마다 비밀번호를 새로 정하게 하는데, **매번 여기 넣은 값과
> 똑같이** 써야 해요. 다르면 파일을 열지 못합니다. 기억하기 쉬운 걸로 정하세요.
>
> 잊어버리셨으면 메뉴의 `상태 보기`에 힌트(`0**0` 같은 모양)가 나와요.
>
> 🔒 **이 값은 시트에 적히지 않아요.** 스크립트 안에만 저장돼서, 시트를 남에게
> 공유해도 비밀번호는 따라가지 않습니다.

### ③ 권한 승인

**"Google에서 확인하지 않은 앱입니다"** 경고가 한 번 뜹니다.

**고급 → (프로젝트 이름)(으)로 이동 → 허용**

> 본인이 만든 사본을 본인 계정에서 돌리는 것이라 나오는 화면입니다.
> 심사받은 앱이 아니라서 회피할 수 없습니다.
>
> 요청하는 권한:
> - **Gmail 읽기** — 뱅크샐러드가 보낸 메일에서 파일을 찾습니다
> - **Drive 읽기·쓰기** — 결과를 내 드라이브에 저장합니다
>
> **데이터는 전부 내 구글 계정 안에만 있습니다.** 만든 사람에게 가지 않습니다.

설치 끝입니다. 매일 오전 7시에 자동으로 돕니다.

**이제 바로 아래 2번을 해주세요.** 아직 돈동생에게 줄 데이터가 하나도 없어서,
지금 물어보면 "처리할 새 메일이 없다"고 나와요.

## 2. 평소 사용

### 데이터 보내기 (유일한 수동 작업)

```
뱅크샐러드 앱 → 메뉴 → 설정 → 데이터 내보내기 → 파일로 받기
→ 이메일 주소 확인 → 비밀번호 입력 (①에서 정한 그 값)
```

주 1회든 매일이든 원하는 만큼 하시면 됩니다. 메일이 오면 알아서 처리합니다.

> 뱅크샐러드는 **최근 1년치만** 내보냅니다. 그래서 꾸준히 보낼수록
> 돈동생이 가진 기록이 길어집니다.

### 물어보기

먼저 쓰시는 AI에서 **구글 드라이브를 연결**해야 해요. 한 번만 하면 됩니다.

| | 어디서 |
|---|---|
| **Claude** | 설정 → 커넥터 → Google Drive → 연결 |
| **ChatGPT** | 설정 → 커넥터(Connectors) → Google Drive → 연결 |
| **Gemini** | 설정 → 앱 → Google Workspace 켜기 |

연결하면 구글 로그인 화면이 한 번 더 뜹니다. 돈동생 설치할 때 쓴 계정으로 로그인하세요.

그다음 이렇게 물어보세요. **아래 문장을 복사해서 붙여넣으시면 돼요.**

```
내 드라이브 k-money 폴더에 있는 latest.json 을 읽고,
이번 달 내 소비가 어땠는지 알려줘.
```

한 번 읽고 나면 그다음부터는 짧게 물어도 알아들어요.

```
1억까지 얼마 남았어?
이번 달 왜 많이 썼어?
구독 다 끊으면 얼마나 빨라져?
내 데이터에 이상한 거 있어?
```

> 방금 만들어진 파일은 AI가 몇 분간 못 읽을 수 있어요. 그러면 5분 뒤에 다시 물어보세요.

## 3. 확인과 문제 해결

시트 메뉴 **`💰 돈동생`** 에서:

| 메뉴 | 언제 |
|---|---|
| **② 지금 한 번 돌리기** | 방금 보낸 메일을 바로 처리하고 싶을 때 |
| **상태 보기** | 마지막으로 언제 돌았는지, 실패했는지 |
| **비밀번호 다시 넣기** | 뱅샐에서 다른 비밀번호를 썼을 때 |
| **업데이트 확인** | 새 버전이 나왔는지. 있으면 안내가 나와요 |

### 잘 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| "처리할 새 메일이 없다" | 뱅샐 메일이 아직 안 왔거나 이미 처리함 | 메일함 확인 |
| "zip 해제 실패" | **비밀번호가 다름** | `비밀번호 다시 넣기` 또는 뱅샐에서 같은 값으로 다시 내보내기 |
| LLM이 파일을 못 찾음 | 방금 만든 파일은 몇 분 뒤에 읽힙니다 | 5분 뒤 다시 |
| 메뉴가 안 보임 | 시트를 새로 열어야 함 | 새로고침 |
| 뱅샐 메일이 안 옴 | 보통 몇 분 안에 와요 | 30분 지나도 안 오면 뱅샐에서 다시 |
| 며칠째 안 돌고 있음 | 시트 `상태 보기`로 확인 | 마지막 실행 시각이 오래됐으면 `② 지금 한 번 돌리기` |

## 4. 알아두면 좋은 것

**데이터가 어디 있나**

```
내 드라이브/k-money/
├── latest.json      LLM이 읽는 것
├── facts-날짜.json   지난 기록
├── status.json      마지막 실행 결과
└── raw/             받은 원본 파일
```

전부 **내 구글 드라이브**입니다. 만든 사람은 볼 수 없습니다.

**LLM에게 물어보면 데이터가 어디로 가나**

내 드라이브에서 **내가 쓰는 LLM 회사**(Anthropic·OpenAI·Google)로 갑니다.
돈동생을 만든 사람에게는 가지 않지만, **LLM 회사에는 갑니다.** 그건 알고 쓰셔야 합니다.

**돈동생이 하지 않는 것**

- 상품 추천, 매매 판단 — 사실과 계산까지만 합니다
- 광고, 중개 수수료 — 팔 게 없습니다
- 유료화 — 없습니다

**그만두려면**

시트를 지우면 자동 실행도 멈춥니다. `k-money` 폴더도 지우면 기록까지 사라집니다.
