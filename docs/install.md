# 돈동생 설치하기

> 자산 같이 봐주는 똑똑한 동생.
>
> 손 대는 시간은 5분쯤이에요. 아래 순서대로 하시면 기다리는 시간 없이
> 10분 안에 첫 결과를 보실 수 있습니다.

---

## 필요한 것

- 구글 계정 (뱅크샐러드 내보내기를 받는 메일 주소)
- 뱅크샐러드 앱
- AI 하나. 무료도 됩니다. 방법이 두 가지예요 — 아래 「물어보기」를 봐주세요.

> **뭘 넘기게 되는지 먼저 보고 싶으시면** [샘플 파일](sample-latest.json)을 열어 보세요.
> 이 모양 그대로 내 드라이브에 생기고, AI가 읽는 것도 이것뿐이에요.
> (링크의 숫자는 전부 지어낸 거예요)

> ⚠️ **뱅크샐러드에 가입한 이메일이 위 구글 계정과 같아야 해요.**
> 뱅샐이 보내는 메일을 돈동생이 읽어야 하거든요. 네이버 메일로 가입하셨다면
> 뱅샐 앱에서 내보낼 때 받는 주소를 지메일로 바꿔 주세요.

---

## 0. 이것부터 — 기다리는 시간이 없어집니다

**설치보다 이걸 먼저 하세요.** 뱅크샐러드가 메일을 보내는 데 몇 분 걸리는데,
지금 눌러 두면 설치를 끝낼 즈음 메일이 도착해 있습니다.

```
뱅크샐러드 앱
  → 하단 탭바에서 가계부
  → 오른쪽 위 톱니바퀴(설정)
  → 파일로 받기
  → 이메일 입력      아래에서 설치할 그 구글 주소
  → 비밀번호 설정    아무거나 정하고 기억해 두세요. 설치 중에 똑같이 넣습니다
```

> 앱 버전에 따라 `홈 → 오른쪽 위 메뉴 → 설정 → 데이터 내보내기` 로도 갑니다.
> 먼저 계좌가 연동돼 있어야 해요. 연동 안 된 계좌의 돈은 파일에 안 담깁니다.

이걸 안 하면 아무 일도 일어나지 않아요. 설치를 다 해도 돈동생이 볼 데이터가
없거든요. **앞으로도 유일하게 손이 가는 일이 이것 하나입니다.**

## 1. 설치 — 화면 셋, 클릭 열두 번쯤

```
① 사본 만들기        링크 열기 → "사본 만들기"                        2번
   (새로고침)         메뉴가 바로 안 뜨는 경우가 있어요                 1번
② 처음 설정하기      메뉴에서 누르면 → 권한 승인이 먼저 뜹니다      2번
③ 권한 승인          계속 → 계정 선택 → 고급 → 이동 → 허용            5번
   승인이 끝나면      비밀번호 입력창이 이어서 나옵니다                 2번
```

**②를 누르면 비밀번호 창이 아니라 권한 승인부터 나옵니다.** 처음 실행이라 그래요.
③이 제일 긴데, "Google에서 확인하지 않은 앱입니다" 라는 빨간 경고가 나오고
허용 버튼이 `고급`이라는 작은 글씨 뒤에 숨어 있습니다. 미리 알고 가시면 안 당황해요.

### ① 사본 만들기

[👉 돈동생 시트 사본 만들기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy)

링크를 열면 "사본 만들기" 버튼이 나옵니다. 누르면 내 구글 드라이브에 복제됩니다.

### ② 처음 설정하기

복제된 시트 상단 메뉴에서 `💰 돈동생` → `① 처음 설정하기`

> **메뉴가 안 보이나요?** 사본을 만든 직후에는 `💰 돈동생` 메뉴가 바로 안 뜨는
> 경우가 있어요. **새로고침(`Ctrl`/`Cmd` + `R`) 한 번**이면 나옵니다.
> 고장이 아니라 구글 시트가 원래 그래요.

뱅크샐러드에서 데이터를 내보낼 때 쓸 비밀번호를 입력합니다.

> **아직 뱅크샐러드에서 아무것도 안 보내셨어도 괜찮아요.** 앞으로 쓸 값을 미리 정하는 거예요.
>
> ⚠️ 뱅크샐러드는 내보낼 때마다 비밀번호를 새로 정하게 하는데, **매번 여기 넣은 값과
> 똑같이** 써야 해요. 다르면 파일을 열지 못합니다. 기억하기 쉬운 걸로 정하세요.
>
> 잊어버리셨으면 메뉴의 `상태 보기`에 힌트가 나와요. 6자 이상이면 **첫 글자·끝
> 글자·자릿수**를, 그보다 짧으면 자릿수만 보여줍니다 — 짧으면 힌트가 곧 답이
> 되거든요. 그게 싫으시면 비밀번호를 따로 적어 두고 힌트를 안 보셔도 됩니다.
>
> 🔒 **이 값은 시트 칸에 적히지 않아요.** 스크립트 설정에만 저장됩니다.
> 시트를 **보기 권한으로** 공유하면 상대는 볼 수 없어요.
> 다만 **편집 권한으로 공유하면** 상대가 스크립트 설정에 들어갈 수 있으니,
> 이 시트는 편집 권한으로 공유하지 마세요.

### ③ 권한 승인 — 여기가 제일 무섭게 생겼어요

빨간 경고가 나옵니다. **정상입니다.** 순서대로만 누르시면 돼요.

```
1. "계속"
2. 구글 계정 고르기 — 뱅샐 메일을 받을 그 계정으로
3. "Google에서 인증하지 않은 앱입니다" 라는 문구가 나옵니다
      → 여기서 대부분 멈추는데, 정상이에요
      → 「고급」 이 보이면 눌러서 "(프로젝트)(으)로 이동" 을 선택하세요
4. 권한 네 개에 전부 체크 — 「모두 선택」 이 제일 간단합니다
5. "계속" 또는 "허용"
```

> ⚠️ **4번에서 체크를 빼지 마세요.** 항목별로 선택할 수 있게 보이지만,
> 하나라도 빠지면 매일 실행이 조용히 멈춥니다. 오류가 뜨는 게 아니라
> 그냥 아무 일도 안 일어나요. 무엇을 허용하는 건지는
> → [6. 권한과 신뢰](#6-권한과-신뢰)

왜 이런 경고가 나오나요? 구글에 심사를 신청하면 사라지지만, 심사에는 비용과
법인이 필요해요. 1인 사이드 프로젝트라 안 받았습니다. 그래서 이 경고는 없앨 수가
없어요. 대신 무엇을 허용하는지는 아래에 다 적어 뒀습니다.

지금 허용하는 건 남의 서버가 아니라 내 계정 안에서 도는 내 스크립트예요.
사본을 지우면 같이 사라집니다.

승인 화면에서 **Gmail 전체 읽기**를 달라고 합니다. 구글이 "이 발신자 메일만"
같은 좁은 권한을 안 주기 때문이에요. 무엇을 주는 건지 하나씩,
그리고 코드를 직접 확인하는 법은 → [6. 권한과 신뢰](#6-권한과-신뢰)

## 2. 평소 사용

### 데이터 보내기 (유일한 수동 작업)

먼저 뱅크샐러드에 계좌가 연동돼 있어야 해요. 연동 안 된 계좌의 돈은
데이터에 안 잡혀서, 나중에 "수입이 왜 이것밖에 안 돼?" 하는 일이 생겨요.

```
뱅크샐러드 앱
  → 하단 탭바에서  가계부
  → 오른쪽 위  톱니바퀴(설정)
  → 파일로 받기
  → 이메일 입력
  → 비밀번호 설정
```

이메일은 돈동생을 설치한 구글 계정 주소여야 해요. 다른 주소로 보내면
돈동생이 메일을 못 찾습니다.

비밀번호는 설치할 때(①) 정한 그 값으로 넣어 주세요. 뱅크샐러드는 내보낼
때마다 새로 물어보는데, 매번 같은 값이어야 파일이 열립니다.
기억이 안 나면 시트 메뉴의 `상태 보기`에 힌트가 있어요.

보내고 나면 보통 몇 분 안에 메일이 옵니다. 그다음은 알아서 처리돼요.
바로 확인하고 싶으면 시트 메뉴에서 `② 지금 한 번 돌리기`를 누르시면 됩니다.

> 뱅크샐러드는 **최근 1년치만** 내보내고 기간을 고를 수 없어요.
> 그래서 꾸준히 보낼수록 돈동생이 가진 기록이 길어집니다.
> 1년 넘게 안 보내면 그 사이 기록은 영영 사라져요.

### 물어보기

한 번 연결해두는 쪽을 권합니다. 매번 파일을 받지 않아도 돼요.

#### 방법 1 — 구글 드라이브 연결하기 (권장)

| | 어디서 |
|---|---|
| **Claude** | 설정 → 커넥터 → Google Drive → 연결 |
| **ChatGPT** | 설정 → **앱(Apps)** → Google Drive → 연결 |
| **Gemini** | 설정 및 도움말 → **연결된 앱** → Google Drive 사용 설정 |

연결하면 구글 로그인 화면이 한 번 더 뜹니다. 돈동생 설치할 때 쓴 계정으로 로그인하세요.
한 번만 해두면 그다음부터는 그냥 물어보시면 됩니다.

> AI 유료 구독이 있어야 해요. 없으시면 아래 방법 2로 가세요 — 결과는 같습니다.

> ⚠️ 드라이브를 연결하면 그 AI는 `돈동생` 폴더뿐 아니라 **내 드라이브의 다른 파일도
> 찾아볼 수 있어요.** 폴더 단위로 좁히는 기능은 AI 쪽에 없습니다. 그게 부담스러우면
> 방법 2가 오히려 낫습니다 — 파일 하나만 주니까요.

그다음 이렇게 물어보세요. 아래 문장을 복사해서 붙여넣으시면 돼요.

```
돈동생 파일 보고 이번 달 내 소비 어땠는지 알려줘
```

폴더나 파일 이름을 외우실 필요 없어요. 파일 이름이 `돈동생-최신.json` 이라
"돈동생" 만 말해도 AI가 찾습니다.

#### 방법 2 — 파일을 직접 올리기 (무료 계정도 됨)

구독이 없거나, AI에게 주는 범위를 좁히고 싶으실 때요.

1. 내 드라이브 → `돈동생` 폴더 → `돈동생-최신.json` 다운로드
2. 쓰시는 AI 창에 그 파일을 끌어다 놓기
3. `이번 달 내 소비 어땠어?` 라고 물어보기

내보내기 할 때마다 파일 하나 더 받는 것뿐이고, **결과는 방법 1과 똑같아요.**

> 무료 요금제도 파일 첨부는 됩니다. ChatGPT 무료는 하루 3개, Claude 무료는
> 대화당 5개까지예요. **Gemini 무료는 json 같은 파일을 아직 못 받을 수 있어요** —
> 안 되면 ChatGPT나 Claude를 쓰세요.

#### 그다음부터

한 번 읽고 나면 짧게 물어도 알아들어요.

```
1억까지 얼마 남았어?
이번 달 왜 많이 썼어?
매달 똑같이 나가는 돈이 얼마야?
내 데이터에 이상한 거 있어?
```

> 방금 만들어진 파일은 AI가 몇 분간 못 읽을 수 있어요. 그러면 5분 뒤에 다시 물어보세요.

## 3. 확인과 문제 해결

시트 메뉴 `💰 돈동생` 에서:

| 메뉴 | 언제 |
|---|---|
| **② 지금 한 번 돌리기** | 방금 보낸 메일을 바로 처리하고 싶을 때 |
| **상태 보기** | 데이터가 언제까지 있는지, 마지막으로 언제 돌았는지 |
| **비밀번호 다시 넣기** | 뱅샐에서 다른 비밀번호를 썼을 때 |
| **버전 보기** | 지금 쓰는 버전. 바뀐 것들은 [여기](../CHANGELOG.md) |

### 잘 안 될 때

| 이런 게 보이면 | 왜 | 어떻게 |
|---|---|---|
| **"압축을 풀지 못했어요"** | 뱅샐에서 정한 비밀번호와 여기 넣은 값이 다름 | `비밀번호 다시 넣기`, 또는 뱅샐에서 같은 값으로 다시 내보내기 |
| **"새로 온 뱅크샐러드 메일이 없어요"** | 아직 안 왔거나 이미 처리함 | 메일함 확인, 또는 앱에서 다시 내보내기 |
| **"데이터가 … 에서 멈춰 있어요"** | 뱅샐에서 안 보낸 지 2주 넘음 | 앱에서 다시 내보내기 (위 2번) |
| **"집계 라이브러리를 불러오지 못했어요"** | 라이브러리 연결이 풀림 | `확장 프로그램 → Apps Script → 라이브러리` 에 `kmoneylib` 이 있는지 확인 |
| 메뉴가 안 보임 | 시트를 방금 열었음 | 새로고침 한 번 |
| 뱅샐 메일이 안 옴 | 보통 몇 분 안에 와요 | 30분 지나도 안 오면 뱅샐에서 다시 |
| AI가 파일을 못 찾음 | 방금 만든 파일은 몇 분 뒤에 읽혀요 | 5분 뒤 다시 |
| 며칠째 안 돌고 있음 | 자동 실행이 풀렸을 수 있음 | `① 처음 설정하기` 를 다시 누르세요. 비밀번호를 한 번 더 넣으면 자동 실행이 다시 걸려요. **쌓인 데이터는 그대로예요** |

그래도 안 되면 [이슈](https://github.com/sbigstar0310/k-money/issues)에 남겨 주세요.
`💰 돈동생 → 버전 보기` 의 두 줄을 같이 적어 주시면 훨씬 빨리 찾습니다.

## 4. 업데이트 — 안 하셔도 됩니다

돈동생은 저절로 업데이트되지 않아요. 설치한 그 버전 그대로 계속 돕니다.
왜 일부러 그렇게 했는지는 [README](../README.md#업데이트는-안-하셔도-돼요)에 적어 뒀어요.

무엇이 바뀌었고 올려야 하는 건지 아닌지는
[바뀐 것들](../CHANGELOG.md)에 버전마다 적어 뒀어요. 🔴 표시가 없으면 안 하셔도 됩니다.

### 지금 뭘 쓰고 있는지 보기

```
💰 돈동생 → 버전 보기
```

두 줄이 나와요. 문제를 알려주실 때 이 두 줄을 같이 적어 주시면 제일 빠릅니다.

| | 뭔가요 | 바꿀 수 있나요 |
|---|---|---|
| **시트 스크립트** | 메일을 찾아오고 시트에 적는 부분 | 아니요. 이 시트 안에 복사돼 있어요 |
| **집계 라이브러리** | 실제로 계산하는 부분 | 네, 아래 방법으로요 |

### 라이브러리 올리기 — 2분, 코드는 안 건드려요

잘 돌고 있으면 안 하셔도 됩니다. 저장소에 "이건 올려 주세요"라고 적힌 게
있을 때만 하시면 돼요.

```
1. 시트 위쪽 메뉴에서  확장 프로그램 → Apps Script
      코드가 잔뜩 있는 화면이 열립니다. 놀라지 마세요.
      아무것도 건드리지 않을 거예요.

2. 왼쪽 아래 "라이브러리" 밑의  kmoneylib  을 클릭

3. "버전" 드롭다운에서  제일 큰 숫자  를 고르세요
      1, 2, 3 … 처럼 생겼어요. 0.1.1 같은 모양이 아닙니다.
      이 둘은 서로 다른 번호라 외우실 필요 없어요. 큰 것만 고르시면 돼요.

4. "저장"

5. 시트로 돌아가서  💰 돈동생 → 버전 보기
      '집계 라이브러리' 숫자가 올라갔으면 끝입니다.
```

비밀번호도, 지금까지 쌓인 데이터도 그대로 있어요. 바뀌는 건 계산하는 부분뿐이에요.

> 되돌리고 싶으면 같은 자리에서 예전 숫자를 다시 고르시면 됩니다.

### 시트 스크립트는 어떻게 하나요

못 바꿉니다. 사본을 만들 때 형 시트 안으로 복사된 것이라, 제가 고쳐도 거기까지
닿지 않아요. 꼭 바꿔야 할 게 생기면 저장소에 따로 안내를 적어 둘게요.
대부분의 개선은 라이브러리 쪽에 들어가서 위 방법으로 받으실 수 있습니다.

## 5. 알아두면 좋은 것

### 데이터가 어디 있나

```
내 드라이브/돈동생/
├── 돈동생-최신.json      AI가 읽는 것
├── 돈동생-날짜.json      지난 기록
├── 돈동생-상태.json      마지막 실행 결과
├── 내정보.json           목표·가정 (직접 올림)
└── raw/             받은 원본 파일
```

전부 내 구글 드라이브예요. **나만 볼 수 있습니다.** 서버가 없어서 데이터가 지나갈 곳이 없어요.

### LLM에게 물어보면 데이터가 어디로 가나

내 드라이브에서 내가 쓰는 LLM 회사(Anthropic·OpenAI·Google)로 갑니다.
돈동생 개발자에게는 안 가지만, AI 회사에는 갑니다. 그건 알고 쓰셔야 해요.

### 돈동생이 하지 않는 것

- 상품 추천, 매매 판단 — 사실과 계산까지만 합니다
- 광고, 중개 수수료 — 팔 게 없습니다
- 유료화 — 없습니다

### 이 프로젝트가 멈추면

계산하는 부분은 개발자 계정의 Apps Script 라이브러리에 있어요. 그게 사라지면
매일 아침 실행이 실패합니다. 다만 두 가지는 그대로예요.

- 이미 만들어진 파일은 내 드라이브에 남아요. 결과도 `raw/`의 원본도요.
- 버전을 고정해 쓰기 때문에, 개발자가 코드를 바꿔도 내 것은 안 바뀌어요.

되살리려면 [GitHub](https://github.com/sbigstar0310/k-money)의 `appsscript/` 에서
`core.gs` · `zipcrypto.gs` · `app.gs` · `library-api.gs` 네 개를 내 스크립트에
새 파일로 붙여넣으세요. 그러면 라이브러리 없이도 계속 돌아요.
네 개를 다 넣어야 해요 — 하나라도 빠지면 중간에 멈춰요.
그다음 왼쪽 `라이브러리` 목록에서 `kmoneylib` 을 지워 주세요.
없어진 라이브러리를 계속 참조하면 실행이 막힐 수 있어요.

### 그만두려면

1. 시트를 지우면 자동 실행이 멈춰요
2. `돈동생` 폴더도 지우면 기록까지 사라져요
3. [내 구글 계정 → 데이터 및 개인정보 보호 → 타사 앱](https://myaccount.google.com/connections)
   에서 권한을 회수하세요. 시트만 지우면 승인은 계정에 남아 있어요

### 목표를 기억하게 하려면

AI에게 "1억 모으고 싶어" 라고 말해도 대화가 끝나면 잊어버려요.
돈동생이 만드는 파일에는 목표가 안 들어 있거든요.

기억하게 하려면 `돈동생` 폴더에 `내정보.json` 이라는 파일을 직접 만들어 두세요.
AI에게 "이 내용으로 내정보.json 을 만들어줘" 라고 하면 내용을 써줍니다.
그걸 드라이브에 올려두면 다음부터 같이 읽어요.

```json
{ "goals": ["3년 안에 5천만원"], "assumptions": { "월수입": 2600000 } }
```

돈동생은 이 값을 계산에 쓰지 않아요. 그대로 실어 나르기만 합니다 —
목표를 숫자로 바꾸는 건 AI가 할 일이에요.

### 원본 zip이 쌓이는 것

`raw/` 폴더의 zip은 자동으로 안 지워져요. 집계 방식을 고쳤을 때 과거를 다시
계산하려고 남겨둬요. 용량이 부담되면 오래된 것부터 지우셔도 됩니다 —
계산된 결과는 그대로 남아요.

## 6. 권한과 신뢰


### 무슨 권한을 주는 건지

승인 화면에 이 네 줄이 나옵니다. 왼쪽이 화면 문구 그대로예요.

| 화면에 이렇게 나와요 | 실제로 할 수 있는 것 | 왜 필요한가 |
|---|---|---|
| 이메일 메시지 및 설정 보기 | **메일함 전체를 읽을 수 있어요.** 뱅샐 메일만이 아닙니다 | 뱅샐이 보낸 zip 첨부를 찾으려고 |
| Google Drive 파일 보기, 수정, 생성, 삭제 | 드라이브 전체를 읽고 쓸 수 있어요 | 결과를 `돈동생` 폴더에 쌓고, xlsx 를 시트로 변환하려고 |
| 모든 Google Sheets 스프레드시트 확인, 수정, 생성, 삭제 | **이 시트만이 아니라 계정의 모든 시트**예요 | 변환한 임시 시트를 열어 읽으려고 |
| 부재중에 이 애플리케이션을 실행하도록 허용 | 매일 아침 예약 실행 | 컴퓨터가 꺼져 있어도 돌게 하려고 |

> ⚠️ **네 개를 전부 체크해 주세요. 「모두 선택」이 제일 간단해요.**
>
> 화면에 항목별 체크박스가 있어서 하나씩 뺄 수 있게 보입니다. 그런데
> **하나라도 빼면 매일 실행이 조용히 깨져요.** 오류 창이 뜨는 게 아니라
> 그냥 아무 일도 안 일어납니다.
>
> Gmail 이 부담되시는 건 당연하고 저도 그게 이 도구의 제일 큰 값이라고
> 생각해요. 다만 **여기서 체크만 빼는 건 중간 선택지가 아니라 고장**입니다.
> 부담되시면 체크를 빼지 마시고 아예 안 쓰시는 게 맞아요.

구글이 "이 발신자 메일만" 같은 좁은 권한을 안 주기 때문에 더 줄일 수가 없어요.
권한은 넓고, 코드는 좁게 씁니다. 실제로 이 검색어에 걸리는 메일만 봐요.

여기 **없는 것**도 봐 주세요. 인터넷에 요청을 보내는 권한이 목록에 없습니다.
직접 세어 보시면 네 줄뿐이에요.

아래 「직접 확인하세요」에서 `appsscript.json` 을 여시면 이 네 줄이 이렇게
적혀 있습니다. 화면 문구와 순서까지 같아요.

| 스코프 | 위 표의 |
|---|---|
| `gmail.readonly` | 첫째 줄 |
| `drive` | 둘째 줄 |
| `spreadsheets` | 셋째 줄 |
| `script.scriptapp` | 넷째 줄 |

여기 없는 것도 봐 주세요. 인터넷에 요청을 보내는 권한(`script.external_request`)을
요구하지 않아요.

> 다만 이걸 "데이터가 절대 못 나간다" 로 읽으시면 안 돼요. 스스로 요청을 못 보낼
> 뿐이고, 넓은 권한으로 우회할 길은 남아 있습니다. 어디까지가 보증이고 어디부터는
> 아닌지 [SECURITY.md](../SECURITY.md)에 정리해 뒀어요.

```
has:attachment filename:zip (뱅크샐러드 OR banksalad)
```


### 못 믿으시면 직접 확인하세요 — 3분이면 돼요

1. 시트 → `확장 프로그램` → `Apps Script`
2. `UrlFetchApp` 을 검색해 보세요. **한 곳도 안 나옵니다.**
   Apps Script 에서 인터넷 요청은 전부 이 이름을 거쳐야 하거든요
3. `PropertiesService` 를 검색해 보세요. 비밀번호가 시트가 아니라 스크립트
   설정에 저장되는 게 여기서 보여요
4. 왼쪽 ⚙️ `프로젝트 설정` → `appsscript.json 매니페스트 파일 표시` 를 켜면
   `oauthScopes` 목록이 그대로 보입니다. 위 표와 같은지 대조해 보세요

여기서 보이는 건 시트에 붙은 코드 하나뿐이에요. 실제로 계산을 하는 집계
코어는 별도 프로젝트(라이브러리)라 편집기에 안 뜹니다 — 메일 검색어도 거기
있어서 여기서 검색하면 안 나와요. 그 코드도
[GitHub 의 `appsscript/`](https://github.com/sbigstar0310/k-money/tree/main/appsscript)
에 다 있지만, **저장소의 코드와 지금 도는 라이브러리가 같다는 건 개발자를
믿는 것 말고 확인할 방법이 없어요.** 라이브러리로 배포하는 방식의 한계입니다.
숨기지 않고 적어 둡니다.

> 대신 확실한 게 하나 있어요. 위 `oauthScopes` 목록은 **라이브러리에도 적용됩니다.**
> 라이브러리는 이 시트의 권한으로 도니까, 목록에 없는 권한은 라이브러리 코드가
> 쓰려고 해도 막혀요. 인터넷 요청 권한이 목록에 없다는 건 그래서 의미가 있습니다.

설치 끝입니다. 매일 오전 7시에 자동으로 돕니다.

> 시트 첫 화면에 **데이터가 언제까지 있는지**가 적혀요. 뱅크샐러드에서 내보내는 걸
> 잊고 지내면 2주 뒤부터 거기에 경고가 뜹니다. 자동 실행은 계속 성공하니까,
> "잘 돌고 있음"만 보고는 데이터가 멈춘 걸 알 수가 없거든요.

0번을 먼저 하셨으면 메일이 이미 와 있을 거예요. 메뉴에서 `② 지금 한 번 돌리기`
를 누르면 바로 정리합니다. 아직 안 하셨으면 지금 0번을 해주세요 — 그게 없으면
돈동생이 볼 데이터가 없습니다.
