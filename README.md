# 돈동생 &middot; [![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

현재 버전 **0.4.5** · [바뀐 것들](CHANGELOG.md)

뱅크샐러드 데이터를 내 구글 드라이브에 정리해 두면, 이미 쓰는 Claude·ChatGPT·Gemini가 읽고 내 돈 얘기를 같이 해줘요.

## 무엇을 물어볼 수 있나

정해진 화면이 아니라, 궁금한 걸 그냥 물어보면 돼요.

```
나:  안 쓰고 놀고 있는 돈이 얼마나 돼?
AI:  자유입출금 1,840만 원 중 1,520만 원이 6개월째 그대로예요.
     월 지출이 210만 원이라 3개월치(630만 원)를 남겨도
     890만 원쯤은 당장 쓸 일이 없는 돈이에요.

나:  그걸 6개월 묶어 두면 얼마나 차이 나?
AI:  예를 들어 연 3.3%로 6개월 묶으면 세후 12만 원쯤,
     연 3.0%로 언제든 뺄 수 있게 두면 11만 원쯤이에요.
     차이는 1만 원 남짓이에요. 묶이는 불편과 견줘 보시면 돼요.
```

```
나:  8월 5일에 나간 7만 원 뭐였어?
AI:  8월 거래 파일을 보니 8월 5일 저녁 7시 42분,
     ○○안경원에서 신한카드로 70,000원 결제했어요.
```

## 시작하기

필요한 건 셋이에요.

- 구글 계정 — 뱅크샐러드 내보내기를 받을 주소
- 뱅크샐러드 앱 — 계좌가 연동돼 있어야 해요
- 컴퓨터 — 설치할 때만요. 그다음은 폰으로 돼요

1. **[시트 사본 만들기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy)** 를 누르고, 사본이 열리면 **새로고침**(`Ctrl`/`Cmd` + `R`)해 주세요.
   그래야 `💰 돈동생` 메뉴가 나와요.
2. `💰 돈동생` → `① 처음 설정하기` 를 눌러요.
   "확인되지 않은 앱" 경고가 뜨고, 체크박스 네 개는 꺼진 채로 나와요. 누를 곳은 [설치 안내](docs/install.md#1-설치--화면-셋-클릭-열세-번쯤)에 있어요.
3. 쓰시는 AI에 구글 드라이브를 연결해요. 구독이 없으면 파일을 올려도 돼요.

화면 순서대로 다 적은 [설치 안내](docs/install.md)도 있어요. 5분쯤 걸려요.

## 그다음엔

뱅크샐러드 앱 → `가계부` → 오른쪽 위 ⚙ → `파일로 받기` 를 눌러요.
뱅샐에는 자동으로 꺼내 주는 기능이 없어서, 이것만은 직접 눌러야 해요.

그러고 1~2분 뒤 AI에게 물어보세요. 컴퓨터가 꺼져 있어도 돼요.
이 1~2분은 **0.4.6부터 만든 사본** 얘기예요. 그 전 사본은 하루 한 번만 정리해요.
→ [새 사본으로 옮기기](docs/install.md#예전에-설치하셨다면--1분-확인으로-옮기기)

AI에게 "갱신해줘"라고 하면 어떻게 답하는지는 [여기](docs/install.md#물어보기) 적어 뒀어요.

## 내 드라이브에 들어가는 것

`돈동생` 폴더에 이런 게 쌓여요.

- **요약 파일** — AI가 먼저 읽는 숫자예요. [이렇게 생겼어요](docs/sample-latest.json)
- **거래내역 시트** — `가계부 내역`(거래 한 건 한 건)과 `뱅샐현황`(이름·성별·나이·신용점수, 계좌·상품별 잔액, 투자 평가액, 대출)
- **달별 거래 파일** — 예전 달은 지우지 않아서 1년보다 오래 쌓여요
- **AI 메모** — 대화에서 AI가 물어보고 적어 둔 목표 같은 것
- **원본 zip** — 뱅샐이 보낸 그대로

이걸 볼 수 있는 건 나, 드라이브나 폴더를 공유받은 사람, 그리고 연결한 AI예요.
비밀번호가 걸린 건 원본 zip뿐이라, AI는 이름과 신용점수까지 읽을 수 있어요.
전체 계좌번호는 없어요(일부 가려진 식별자는 있어요).
저희 서버로는 아무것도 안 와요. 다만 AI에게 물어보면 그 AI 회사로는 가요.
자세한 건 [SECURITY.md](SECURITY.md)에 있어요.

## 믿을 수 있나

- 코드가 전부 [여기](https://github.com/sbigstar0310/k-money) 공개돼 있어요.
- 스크립트가 밖으로 요청을 보내지 않아요. 코드에 `UrlFetchApp`이 한 곳도 없어요.
- 뱅샐 메일을 찾으려고 **Gmail 전체 읽기** 권한을 받아요. 구글이 더 좁은 권한을 주지 않아서예요.
- 광고도 수수료도 없어요.

어디까지 보증되고 어디부터 안 되는지는 [SECURITY.md](SECURITY.md)에, 직접 확인하는 법은 [설치 안내](docs/install.md#6-권한과-신뢰)에 있어요.
