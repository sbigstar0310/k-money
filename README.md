# 💰 돈동생 (k-money)

> **자산 같이 봐주는 똑똑한 동생.**
>
> "1억까지 얼마 남았어?" 하고 물으면 네 실제 데이터로 계산해서 답한다.
> 데이터는 네 구글 드라이브에만 있고, 우리는 아무것도 팔지 않는다.

### [👉 시작하기 — 시트 사본 만들기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy)

설치 3분. 그다음부터는 알아서 돕니다.
자세한 절차는 **[설치 안내](docs/install.md)**.

## 이게 뭔가

가계부 앱은 "이번 달 68만원 썼어요"까지만 말해 줍니다. **그래서 어쩌라는 건지**는 안 알려주죠.

돈동생은 뱅크샐러드 데이터를 자동으로 받아 정리해서 **네 구글 드라이브에** 놓습니다.
그러면 **네가 이미 쓰는 Claude·ChatGPT·Gemini**가 그걸 읽고 대화합니다.

```
유저: 1억까지 얼마 남았어?
 AI:  8,461만원 남았어요. 그런데 최근 1년 순현금흐름이 월 −20만원이라
      지금 페이스로는 오히려 멀어지는 중이에요.
      다만 4·5월 온라인쇼핑 급증 311만원을 일회성으로 보면 월 +8.6만원입니다.
      이거 계속될 지출인가요?

유저: 아니 그때 노트북 샀어
 AI:  그러면 월 8.6만원 기준으로 다시 볼게요. 다만 1억까지는…
```

**세 번째 줄이 다른 앱이 못 주는 것입니다.** 되물을 수 있다는 것.

---

## 누구를 위한 것인가

**LLM은 익숙한데 돈 관리는 처음인 사회 초년생.**

이미 AI에게 뭐든 물어보지만, **자기 실제 금융 데이터로는 못 물어봅니다.**
"ChatGPT한테 물어보면 되지 않나?"는 맞는 직감인데, 데이터를 못 물려서 일반론만 돌아옵니다.

**아닌 사람**: 예산 세우고 지키는 훈련이 목적인 분 (→ 카카오페이 AI코치, Actual Budget).

## 뭘 물어볼 수 있나

```
"이번 달 왜 많이 썼어?"          카테고리별로 어느 달에 뭐가 튀었는지 압니다
"구독 다 끊으면 얼마나 빨라져?"    살아 있는 것과 이미 해지한 것을 구분합니다
"내 데이터에 이상한 거 있어?"      수입이 덜 잡혔는지, 연동 안 된 계좌가 있는지
"저축률이 얼마야?"                믿을 수 없으면 숫자를 내놓지 않고 이유를 말합니다
```

마지막 줄이 중요합니다. **틀린 숫자를 자신 있게 말하느니 말하지 않습니다.**

## 데이터는 어디에

```
내 드라이브/k-money/
├── latest.json      LLM이 읽는 것
├── facts-날짜.json   지난 기록
└── raw/             받은 원본
```

전부 **내 구글 계정 안**입니다. 만든 사람은 볼 수 없습니다. 서버가 없습니다.

> ⚠️ 다만 LLM에게 물어보면 **내가 쓰는 LLM 회사**(Anthropic·OpenAI·Google)로는 갑니다.
> 돈동생을 만든 사람에게는 안 가지만, 그건 알고 쓰셔야 합니다.

## 하지 않는 것

- **상품 추천·매매 판단** — 사실과 계산까지만 합니다
- **광고·중개 수수료** — 팔 게 없습니다
- **유료화** — 없습니다

기존 서비스는 어딘가에서 반드시 수익화 지점을 보여야 합니다. 뱅샐은 대출·카드 중개
수수료, 로보어드바이저는 수익금의 연 9.5%. **우리는 파이프라인을 만들어 배포할 뿐이라
그 지점이 없습니다.** 그리고 개인화된 금융 조언에 대가를 받는 순간 투자자문업 인가
영역입니다. 무료는 선택이 아니라 구조입니다.

## 조용히 돌아가는 것 — 데이터 감사

차별점이 아니라 **위생 요건**입니다. 화면 앞에 안 세웁니다. 그러나 없으면 숫자가 거짓말을 합니다.

실데이터에서 발견한 함정 13개 중 넷:

| 함정 | 놓치면 |
|---|---|
| '이체'를 수입·지출로 이중계상 | 509건 **912만원** 왜곡 |
| 지출이 **음수**로 저장됨 | 저축률 **24,305%** |
| 환불 = 타입 '지출' + **양수** | 오차가 환불액의 **2배** |
| 구독 연액 = 월평균 × 12 | 보고액의 **66%가 허수** |

전부 그럴듯한 숫자라 눈으로는 안 걸립니다. 각각 회귀 테스트가 있습니다.

## 개발자를 위해

```sh
npm test              # 회귀 테스트 48개 (의존성 0, node ≥ 20)
npm run check         # 빌드 + 테스트
npm run build         # core/ → appsscript/core.gs
```

**코어는 순수 JS 한 벌**입니다. node로 검증한 **같은 파일**이 Apps Script에서 돕니다.
포팅 단계가 없으므로 두 구현이 어긋날 수 없습니다.

```
core/       model · layout · analyze · parse · profile · aggregate
appsscript/ main(유저 프로젝트) · core+library-api(라이브러리)
```

### 설계 원칙

> **우리가 파는 건 산수가 아니라 "어떤 식을 쓸지"다.**

| 넣는다 | 뺀다 |
|---|---|
| 원본을 훑어야 나오는 것 | 식이 하나뿐인 것 (뺄셈·나눗셈 한 번) |
| 그럴듯한 식이 여럿인데 **하나만 맞는** 것 | **우리가 상수를 고른** 것 |
| 대화 한 세션이 원리적으로 모르는 것 | 문장·어투·심각도 판정 |

문장은 LLM이 씁니다. 우리는 숫자만 책임집니다.

> ⚠️ `.env`, `secrets/`, `data/`, `fixtures/` 는 gitignore 됩니다.
> **금융 데이터와 시크릿을 커밋하지 마세요.**
