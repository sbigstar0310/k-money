# 돈동생 &middot; [![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

현재 버전 **0.4.5** · [바뀐 것들](CHANGELOG.md)

돈동생은 뱅크샐러드 데이터를 정리해서 내 구글 드라이브에 놓아주는 도구예요.
이미 쓰고 있는 Claude나 ChatGPT가 그걸 읽고 내 자산 얘기를 같이 해줘요.

가계부 앱은 "이번 달 68만원 썼어요"까지만 알려줘요. 그래서 뭘 해야 하는지는 안 알려주죠.
돈동생은 자유롭게 어떤 질문이든 AI와 대화하면 돼요.

### [→ 시작하기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy)

**뱅크샐러드 메일을 받을 구글 계정**으로 로그인한 상태에서 눌러 주세요.

사본이 만들어지면 **새로고침(`Ctrl`/`Cmd` + `R`)을 해주세요.** 
그래야 상단에 `💰 돈동생` 메뉴가 나옵니다.

## 이렇게 쓸 수 있어요

```
나:  내 30세 목표(1억)까지 얼마 남았어?
AI:  7,200만원 남았어요. 그런데 최근 순현금흐름이 월 −18만원이라
     지금 페이스로는 오히려 멀어지는 중이에요.
     다만 4·5월 온라인쇼핑이 300만원쯤 튀었는데, 일회성이면 월 +7만원이에요.

나:  아 그때 노트북 샀어
AI:  그러면 월 7만원 기준으로 다시 볼게요.
```

```
나:  내 노는 돈을 집어 넣기에 좋은 금융 상품 없을까?
AI:  자유입출금 1,840만원 중 1,520만원이 6개월째 안 움직였어요.
     월 지출이 210만원이니, 비상금 3개월치로 잡으면
     890만원은 묶어도 되는 돈이에요.

     오늘 찾아보니 이렇게 갈려요. (2026-08-09 기준, 세전)
     · 파킹통장     연 2.8~3.2%   언제든 출금, 대개 한도가 있어요
     · 6개월 예금   연 3.3~3.5%   중도해지하면 이자를 거의 못 받아요
     · CMA(RP)      연 3.0% 안팎  예금자보호 대상이 아니에요

     890만원을 3.3%에 6개월 두면 세후 12만원쯤이고,
     1억까지 가는 페이스가 월 2만원 빨라져요.

나:  6개월은 좀 긴데
AI:  그러면 파킹통장이에요. 차이가 6개월에 1만5천원 정도라,
     묶이는 게 싫으면 그 값을 내는 게 맞아요.
```

**자유로운 질문**이 다른 앱과 다른 점이에요.

AI에게 실제로 넘어가는 파일은 [이렇게 생겼어요](docs/sample-latest.json).

## 시작하기 전에

- 구글 계정
- 뱅크샐러드 앱. (계좌가 연동돼 있어야 해요)
  - 토스나 카카오뱅크가 아니라 뱅샐인 이유는 **파일로 내보내기가 되기 때문**이에요.
- AI 구독 모델 (ChatGPT, Claude, Gemini, ...), 구글 드라이브를 연결해두면 제일 편해요.
  - 구독이 없으면 파일을 받아서 올리셔도 됩니다.
- **설치는 컴퓨터에서 해야 해요.** 폰에서는 안 됩니다.
  - 구글 시트 앱에는 `💰 돈동생` 메뉴가 아예 안 나와요. 설치만 컴퓨터로 하시면 그 다음부터는 폰으로도 됩니다.

## 설치 — 한 번만

1. [시트 사본 만들기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy) → **새로고침** (`Ctrl`/`Cmd` + `R`)
  - **뱅크샐러드 내보내기를 받을 주소가 시트 사본의 구글 계정이어야 해요.**
2. 시트 메뉴에서 `💰 돈동생` → `① 처음 설정하기`
3. 권한 승인 — **체크박스 네 개를 직접 켜기** → 그다음 비밀번호 정하기
4. 쓰시는 AI(ChatGPT, Claude, Gemini)에 구글 드라이브 연결하기 (구독이 없으면 파일을 직접 올리기)

**1~3번에 누르는 건 열세 번쯤**이에요. 4번은 쓰시는 AI마다 달라요.
미리 알고 가시면 좋은 것 둘:

- 2번을 누르면 비밀번호 창이 아니라 **권한 승인부터** 나오고, 거기서
  **"Google에서 확인하지 않은 앱"** 이라는 경고가 뜹니다. 정상이에요
- 승인 화면의 **체크박스 네 개는 꺼진 채로 나옵니다.** 켜지 않고 "허용"을 누르면
  권한 없이 승인만 끝나고, **시트에는 아무 표시도 안 납니다**

[설치 안내](docs/install.md)에 화면 순서대로 적어뒀습니다. (5분 소요)

## 그 다음부터 하실 일은 이것 하나예요

```
# 수동으로 해야 해요

뱅크샐러드 앱
  → 하단 탭바에서 가계부
  → 오른쪽 위 톱니바퀴(설정)
  → 파일로 받기
  → 기간 선택        길게 잡을수록 좋아요 (최소 1년)
  → 이메일 입력      돈동생 설치할 때 쓴 구글 주소로
  → 비밀번호 설정    설치할 때 정한 그 값으로
```

주 1회든 매일이든 원하는 만큼 하시면 돼요.

**메일이 오면 나머지는 알아서 돼요.** 컴퓨터도 폰도 꺼져 있어도 됩니다.

```
# 자동으로 됩니다

매일 아침 7시
  → 메일에서 파일 찾기      언제나 가장 최근 것 하나만 봐요
  → 압축 풀고 원본 보관
  → 표로 바꿔서 읽기
  → 계산                   월별·카테고리별·구독·급증·이체·투자
  → 지난번과 비교
  → 드라이브에 저장
```

## 자동으로 못 하는 것

뱅크샐러드는 **데이터를 꺼내는 API가 없어요.** 그래서 내보내기는 사람이 앱에서 눌러야 해요.

## 업데이트는 안 하셔도 돼요

저절로 안 바뀝니다. 설치한 그 버전 그대로 계속 돌아요.

지금 버전은 `💰 돈동생` → `버전 보기`에서 볼 수 있어요.
[바뀐 것들](CHANGELOG.md)에 버전에 저세히 적어 뒀습니다.
업데이트 방법은 [설치 안내](docs/install.md#4-업데이트--안-하셔도-됩니다)에 있고 간단해요.

## 데이터는 내 드라이브에만 있어요

결과는 내 구글 드라이브의 `돈동생` 폴더에 쌓여요. **나만 볼 수 있습니다.**
누구도 이 데이터에 접근 할 수 없어요.

올라가는 건 **숫자 파일 하나**([이렇게 생겼어요](docs/sample-latest.json))와,
**AI가 스스로 적어 둔 메모**예요.

| 들어가요 | 안 들어가요 |
|---|---|
| 월별 수입·지출, 카테고리별 금액 | 계좌번호, 카드번호 |
| 자주 간 가게 이름과 횟수 | 뱅크샐러드 로그인 정보 |
| 계좌별 잔액, 대출 잔액 | 거래 한 건 한 건의 시각·상세 |
| 보유 종목·원금·평가액 | 이름, 주민번호, 연락처 |

**가게 이름이 그대로 들어갑니다.** 병원이나 약국을 자주 갔다면 그것도요.
어디를 다녔는지 알려지는 게 부담되면 안 쓰시는 게 맞아요.

### AI가 적어 두는 메모 — `돈동생/메모리/`

대화에서 "3년 안에 5천만원 모으고 싶어" 같은 걸 말하면, AI가 **"메모리에
적어둘까요?" 라고 물어봅니다.** 승인하시면 마크다운 파일로 남아서, 다음
대화에서 다시 설명 안 하셔도 돼요. **이 글도 다음번에 AI에게 같이 넘어갑니다.**

- **평문이에요.** 드라이브를 볼 수 있는 사람은 다 읽습니다
- **마음에 안 들면 그 파일을 지우시면 돼요.** 돈동생은 이 글을 계산에 안 씁니다

자세한 건 [SECURITY.md](SECURITY.md#알려진-위험)에 적어 뒀어요.

상품을 추천하거나 사고팔라고 하지 않아요. 사실과 계산까지만 해요.
광고도 수수료도 없어요. 유료화 계획도 없고요.

## 믿을 수 있나

Gmail을 읽는 도구라 당연한 걱정이에요. 직접 확인하실 수 있게 만들었어요.

- 코드는 전부 여기 있어요 — [github.com/sbigstar0310/k-money](https://github.com/sbigstar0310/k-money)
- 시트에서 `확장 프로그램 → Apps Script`를 열면 **이 시트가 돌리는 코드**를 볼 수 있어요.
  집계 코어는 별도 프로젝트라 여기 안 뜨는데, 그것도 저장소에 다 있어요
- 거기서 `UrlFetchApp`을 검색해 보세요. **한 곳도 안 나옵니다.** 승인 화면에도
  인터넷 요청 권한이 없어요

다만 이걸 "데이터가 절대 안 나간다"로 읽으시면 안 돼요. 드라이브 권한이 넓어서
마음먹으면 파일을 밖에 열어둘 수는 있어요. 권한 목록으로 증명되는 건 여기까지고,
그 너머는 코드를 보셔야 합니다. 어디까지 보증되고 어디부터 안 되는지
[SECURITY.md](SECURITY.md)에 다 적어 뒀어요.

권한은 구글이 좁게 안 줘서 **Gmail 전체 읽기**를 받게 돼요. 뱅샐 메일만 읽는 권한이
없거든요. 그게 불편하시면 안 쓰시는 게 맞아요.

문제를 발견하시면 [이슈](https://github.com/sbigstar0310/k-money/issues)로 알려주세요.
보안 문제는 [SECURITY.md](SECURITY.md)를 봐주세요.

집계 코어는 순수 JavaScript 한 벌이에요. **node로 검증한 같은 파일이 Apps Script에서 돌아갑니다** —
두 벌로 갈라지면 반드시 어긋나고, 어긋난 걸 늦게 알게 되거든요.

```sh
npm test       # 회귀 테스트
npm run check  # 빌드 + 테스트 (커밋 전에는 이걸로)
```

`npm test` 만으로는 부족해요. 안전장치 하나가 **커밋된 `core.gs`가 지금 `core/`에서
나온 것인지** 보는 건데, 그건 빌드를 돌려야 판정됩니다. 실제로 `core/`를 고치고
빌드를 안 한 채 테스트가 전부 초록이었던 적이 있고, 그때 유저에게 나가는 건
커밋된 옛 번들이었어요. CI가 매 푸시마다 `npm run check`를 돌립니다.

```
core/          집계 코어. 뱅샐도 구글도 모르는 순수 함수
appsscript/
  app.gs         파이프라인. 라이브러리에 있어서 고칠 수 있어요
  container.gs   유저 시트 안의 사본. 한 번 복사되면 못 고쳐요
  core.gs        core/ 의 빌드 산물
```
