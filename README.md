# 돈동생 &middot; [![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

돈동생은 뱅크샐러드 데이터를 정리해서 내 구글 드라이브에 놓아주는 도구예요.
그러면 이미 쓰고 있는 Claude나 ChatGPT가 그걸 읽고 내 돈 얘기를 같이 해줘요.

가계부 앱은 "이번 달 68만원 썼어요"까지만 알려줘요. 그래서 뭘 해야 하는지는 안 알려주죠.
돈동생은 숫자를 정리해서 넘길 뿐이고, 이야기는 AI와 하면 돼요.

### [→ 시작하기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy)

## 이렇게 쓸 수 있어요

```
나:  1억까지 얼마 남았어?
AI:  7,200만원 남았어요. 그런데 최근 1년 순현금흐름이 월 −18만원이라
     지금 페이스로는 오히려 멀어지는 중이에요.
     다만 4·5월 온라인쇼핑이 300만원쯤 튀었는데, 일회성이면 월 +7만원이에요.

나:  아 그때 노트북 샀어
AI:  그러면 월 7만원 기준으로 다시 볼게요.
```

```
나:  구독 다 끊으면 얼마나 빨라져?
AI:  지금 살아 있는 건 6개, 월 12만원이에요.
     이미 해지한 4개는 뺐어요.
```

되물을 수 있다는 게 다른 앱과 다른 점이에요.

## 시작하기 전에

- 구글 계정 하나
- 뱅크샐러드 앱. 계좌가 연동돼 있어야 해요
- **뱅크샐러드 내보내기를 받을 주소가 그 구글 계정이어야 해요.** 여기가 제일 자주 걸려요
- AI 하나. **무료도 됩니다** — 파일을 직접 올리는 방법이 있어요
- 설치는 컴퓨터에서 해주세요. 권한 승인 화면이 폰에서는 다루기 어려워요

## 설치 — 한 번만

1. [시트 사본 만들기](https://docs.google.com/spreadsheets/d/1Gp-RZthttda29uISY6VfJpe7js3Vc2Wksf2cdKpfgCE/copy)
2. 시트 메뉴에서 `💰 돈동생` → `① 처음 설정하기` → 앞으로 쓸 비밀번호 정하기
3. 권한 승인
4. 쓰시는 AI에 `latest.json` 올리기 (구독 중이면 구글 드라이브 연결로 자동화)

설치 자체는 5분쯤이지만, 데이터를 보내고 메일이 오는 걸 기다려야 해서
처음 결과를 보기까지는 20~30분쯤 잡아 주세요.
자세한 건 [설치 안내](docs/install.md)에 적어뒀어요.

## 그다음부터 하실 일은 이것 하나예요

```
뱅크샐러드 앱
  → 하단 탭바에서 가계부
  → 오른쪽 위 톱니바퀴(설정)
  → 파일로 받기
  → 이메일 입력      돈동생 설치할 때 쓴 구글 주소로
  → 비밀번호 설정    설치할 때 정한 그 값으로
```

주 1회든 매일이든 원하는 만큼 하시면 돼요.

메일이 오면 나머지는 알아서 돼요. 컴퓨터도 폰도 꺼져 있어도 됩니다.

```
매일 아침 7시
  → 메일에서 파일 찾기      이미 본 메일은 건너뛰어요
  → 압축 풀고 원본 보관
  → 표로 바꿔서 읽기
  → 계산                   월별·카테고리별·구독·급증·이체·투자
  → 지난번과 비교
  → 드라이브에 저장
```

14초 걸려요. 실패하면 시트에 이유가 적혀요.

## 자동으로 못 하는 것

뱅크샐러드는 **데이터를 꺼내는 API가 없어요.** 그래서 내보내기는 사람이 앱에서 눌러야 해요.
솔직히 이게 이 도구의 한계고, 여기서 그만두게 되는 게 제일 흔한 실패예요.

비밀번호를 매번 넣어야 하는 것도 뱅크샐러드 쪽 정책이라 어쩔 수 없어요.

## 데이터는 내 드라이브에만 있어요

결과는 내 구글 드라이브의 `k-money` 폴더에 쌓여요. 만든 사람은 볼 수 없고, 서버도 없어요.

다만 AI에게 물어보면 내가 쓰는 AI 회사로는 데이터가 가요.
돈동생을 만든 사람에게 안 갈 뿐이지, Anthropic이나 OpenAI에는 가요. 그건 알고 쓰셔야 해요.

상품을 추천하거나 사고팔라고 하지 않아요. 사실과 계산까지만 해요.
광고도 수수료도 없어요. 유료화 계획도 없고요.

## 만드는 중이에요

혼자 만드는 사이드 프로젝트예요. 제 데이터로 먼저 써보면서 다듬고 있어요.

- [설치 안내](docs/install.md) — 처음 쓰는 분을 위한 안내
- [결정 기록](docs/DECISIONS.md) — 왜 이렇게 만들었는지, 무엇을 뒤집었는지
- [내부 구조](docs/internals.md) — 기술 스택과 파이프라인
- [배포](docs/deploy.md) — 라이브러리 배포와 버전 갱신

```sh
npm test      # 회귀 테스트 48개
npm run check # 빌드 + 테스트
```

집계 코어는 순수 JavaScript 한 벌이에요. node로 검증한 같은 파일이 Apps Script에서 돌아가요.

## 믿을 수 있나

Gmail을 읽는 도구라 당연한 걱정이에요. 직접 확인하실 수 있게 만들었어요.

- 코드는 전부 여기 있어요 — [github.com/sbigstar0310/k-money](https://github.com/sbigstar0310/k-money)
- 시트에서 `확장 프로그램 → Apps Script`를 열면 **돌아가는 코드 전문**을 볼 수 있어요
- 거기서 `UrlFetchApp`을 검색해 보세요. **한 곳만 나옵니다** — 업데이트 버전 숫자를
  받아오는 곳이에요. 매일 자동으로 도는 경로에는 외부 통신이 한 줄도 없어요

권한은 구글이 좁게 안 줘서 **Gmail 전체 읽기**를 받게 돼요. 뱅샐 메일만 받는 권한이
없거든요. 권한은 넓고 코드는 좁게 씁니다. 그게 불편하시면 안 쓰시는 게 맞아요.
